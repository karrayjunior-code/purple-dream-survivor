# Purple Dream Survivor

Survivors-like 3D low-poly en el navegador (Three.js), con estética *old dark fantasy* / dreamcore.
Eres un mago con sombrero de punta y tus hechizos surrealistas se lanzan solos.

## Jugar
Abre `index.html` en el navegador (o la versión publicada en GitHub Pages).

- PC: WASD o flechas · P para pausa
- Móvil: arrastra el dedo

## Estado
Demo inicial: 6 poderes, 5 pasivas, 6 tipos de enemigo y el jefe "Sol con Cara".
Objetivo: publicarlo en CrazyGames.
